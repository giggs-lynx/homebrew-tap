# Giggs-lynx Tap

## How do I install these formulae?

`brew install giggs-lynx/tap/<formula>`

Or `brew tap giggs-lynx/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "giggs-lynx/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
